# 配置对照表

## Storage 布局（两代同构）

```
slot0  address owner
slot1  [tier3][tier2][tier1][dynFlag]   三个 uint24 + 0x800000 动态费标志
slot2  [thrA][thrB][thrC]               三个 uint24 阈值（切分存疑）
slot3  uint256 gasThreshold             判罚门槛
slot4  mapping(poolId => uint256)       swap 计数器
```

## beforeSwap 返回值格式

返回 96 字节，三个 word：

```
word0  0x575e24b4...    selector
word1  0x00...00        BeforeSwapDelta (ZERO)
word2  0x00...400000    低22位 = lpFee, bit22 = OVERRIDE_FLAG
```

⚠️ **踩坑记录**：费率在 **word2（偏移 64）**。
早期误读偏移 36，导致所有扫描返回假的 fee=0 —— 包括本该命中 gas 假设的那一次。
