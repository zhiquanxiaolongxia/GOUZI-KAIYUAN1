## 8946B vs 5131B 差异

| 维度 | 5131B（五代） | 8946B（升级版） |
|---|---|---|
| 核心机制 | 掷骰子 | **同样是掷骰子** |
| gas 门 | 5,000,000 | 6,000,000 |
| 种子额外成分 | — | **+ chainid + address(this)** |
| 全局折扣 | 无 | **有（slot6）** |
| `CALL` | 0（无转账能力） | **3（有提现口）** ⚠️ |
| `TLOAD/TSTORE` | 0 | 有 |
| 费率档 | — | 5% / 7.5% / 10%，八折后 4% / 6% / 8% |

**结论：8946B 是 5131B 的参数化增强版，不是新机制。**

## 期望费率

- A：`0.70×4% + 0.15×6% + 0.05×8% + 0.10×0 = 4.1%`
- B：`0.60×4% + 0.10×6% + 0.10×8% + 0.20×0 = 3.8%`

B 对交易者更友好（免费概率 20% vs 10%），但 10% 档触发率也更高（10% vs 5%）—— 方差更大。
